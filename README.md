# АвтоИгнат — тема WordPress

Публичный сайт: **[autoignat.ru](https://autoignat.ru)**  
Личный байер автомобилей из Японии, Кореи и Китая. Тема `auto-ignat` — тёмный/светлый макет, аукционные витрины, цена «под ключ», журнал и формы заявок.

Этот репозиторий — **витрина портфолио**: без секретов, без боевого деплоя и без внутренней документации заказчика.

## Что внутри

- WordPress-тема `wp-content/themes/auto-ignat/`
- Витрины лотов JP / KR / CN (живой API аукциона)
- Страницы доставки, каталог, карточка лота, журнал
- Светлая/тёмная тема (`localStorage`: `ai-theme`)

## Стек

PHP 8 · WordPress · nginx · FastCGI cache

Публичный домен сайта — `autoignat.ru`. Имя репозитория и каталог темы — не адреса сайта.
